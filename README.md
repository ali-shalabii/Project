# BASMA | بصمة

## ملفات الموقع (ارفعها كلها على GitHub، في المجلد الرئيسي)
- index.html  — صفحة الدخول (مع «الدخول كزائر»)  ← أول صفحة يراها الزائر
- app.html    — المنصة (الطالب / الزائر / المعلم / الإدارة)
- welcome.html — صفحة التعريف بالمنصة وللمدارس (نموذج طلب التجربة)
- data.js     — المحتوى: القصص والمصادر وبيانات الخريطة
- config.js   — ضع فيه رابط Supabase والمفتاح العام (مرة واحدة فقط)
- (احذف login.html القديم من الريبو إن كنت رفعته)

## الصور (اختياري)
ضع الصور في مجلد اسمه images داخل الريبو بهذه الأسماء بالضبط، وإلا يظهر رسم بديل تلقائيًا:
iris-haynei.jpg · palestine-sunbird.jpg · olive.jpg · cyclamen.jpg · honeybee.jpg
استخدم صورًا مرخّصة للاستخدام (مثل Wikimedia Commons) أو صورك، واكتب اسم المصوّر في حقل credit داخل data.js.
